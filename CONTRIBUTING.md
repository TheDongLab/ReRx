# Contributing

Report issues or propose changes through [TheDongLab/ReRx](https://github.com/TheDongLab/ReRx). Include the code version, affected script, command/parameters, actual and expected behavior, and relevant package versions. Use synthetic or shareable aggregate examples; exclude participant identifiers, records, credentials, and restricted extracts.

For scientific changes, explain the affected cohort definition, exposure/outcome rule, model, or figure and compare the resulting aggregate outputs in an authorized environment. Keep documentation changes distinguishable from analytical changes and update the README, data guide, and dependency inventory when paths or dependencies change.

Run the syntax checks listed in the README before proposing a change, and validate affected analyses with authorized inputs where available. Report the checks performed and any unresolved issues; syntax checks are not a substitute for scientific validation. Contributions are proposed under the repository's MIT license. Discuss third-party data/asset permissions separately.

Be respectful in discussions, credit contributors, and address reproducibility problems with concrete evidence. Scientific and reproducibility contact: Xianjun Dong, xianjun.dong@yale.edu.
